JARVIS PHASE 10 - PERSONALITY AND VOICE: THE QUESTIONS THE USER MUST ANSWER
=============================================================================
Written 2026-10-16 from a review of PHASE 10 in JARVIS-Repair-Plan.txt (line ~3707), plus 6c, 6e, 6g, 6h
(Phase 6 specs it holds), the evidence list a-e, and the code that exists today.

HOW TO USE THIS FILE (for a NEW chat)
  1. The new chat reads: CLAUDE.md, CLAUDE-READ-BEFORE-RUNNING-ANYTHING.md, then this file, then PHASE 10 in the plan.
  2. It asks the user the questions below IN CHAT, one SECTION at a time (not all 100 at once), and writes each answer
     back into the "ANSWER:" line of this file (or into a copy), so nothing is lost between chats.
  3. The plan's rule stands: NOTHING in Phase 10 is built until the user's hand-review feedback is in
     (plan: "YOUR REVIEW FIRST"). The voice part (sections K-M) does not wait for the personality review, but still needs
     the user's word to start.
  4. Claude must not invent answers. "Skip" and "decide for me" are valid answers; record them as such.
  5. Any answer that changes code goes through the project rules: smallest change, goal / scope / non-goals /
     acceptance / validation / risks / rollback, tests with fakes, commit by file name, no live test until the very end.
  How to answer fast: a letter, a number, "default", or one sentence. Free text is always welcome.
