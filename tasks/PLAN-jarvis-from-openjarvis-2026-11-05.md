## 2. What JARVIS does better and should NOT change
1. **Voice stack**: wake word, echo-cancelled stop words, barge-in, persistent WASAPI player, timed follow-up modes. OpenJarvis has none of it; do not "simplify" toward its press-Enter loop.
2. **Deterministic first**: rules decide, the model only chats or re-reads near-misses. OpenJarvis pays a model call per tool decision.
3. **OS safety**: fixed action table, spoken confirmation with echo/confidence guards, protected processes, typed turns not confirmed by the microphone. OpenJarvis `shell_exec` is unrestricted by default.
4. **Code-owned replies and filters**: claims filter, no-hope, grounded readings, crisis line, persona in code. Keep.
5. **Counts-only log**, local-by-default, `online.py` rule that fetched text never reaches the model.
6. **Test culture**: tripwire runner, golden routes/replies, scored semi-live banks. Adopt OpenJarvis's *automation* of it, not its test style.

## 3. Ranked proposals (OpenJarvis-derived)

Ranking = value for you / (cost x risk). "Live" = needs you at the PC. All items are **plans**; none is approved.

### A-01 Put the gate in the repo and add lint — cost small, risk none, live no  (do first)
- **Goal:** one command runs the whole gate; style/obvious bugs caught before a run. The gate script lived in `%LOCALAPPDATA%\Temp\jarvis-gate\` and referenced worktrees that no longer exist (`RainmeterSpaceship-refactor2`); I had to rebuild it for this review.
- **Scope:** commit a `tools/gate.sh` (the one used in this review, parametrised on repo path) + `tools/gate.cmd` wrapper; add `ruff.toml` limited to pyflakes-class rules (E9, F) so existing style is not churned; optional `.pre-commit-config.yaml` that only runs pyflakes.
- **Non-goals:** no formatter, no reformatting of existing files, no GitHub Actions (no remote).
- **Acceptance:** gate prints the same eight results as the baseline in the review; `ruff check --select E9,F` is clean or its findings are listed (not auto-fixed).
- **Validation:** run twice on a clean tree; deliberately break one assert and see rc=1.
- **Rollback:** delete the new files.

### A-02 `tools/doctor.py` self-check — cost medium, risk low, live partly
- **Goal:** one read-only report (and `--json`) of JARVIS health: venv packages (`missing_packages`), Ollama up + chosen model installed, Whisper/Kokoro/Vosk/openWakeWord files present, microphone and output devices listed, `Settings.inc` parses and passes the schema, `Data` writable, log size, GPU/VRAM headroom with a model suggestion (borrowing OpenJarvis `recommend_engine` idea).
- **Scope:** extends `check_voice.py`; reuses `config.py` schema; checks run concurrently like OJ `doctor_cmd._probe_engines`; prints a hint line per failure (OJ `hints.py` style, JV wording).
- **Non-goals:** no repairs, no installs, no process starts, no network except `localhost:11434/api/tags`.
- **Acceptance:** exits 0 on a healthy machine; each simulated fault (Ollama stopped, model missing, bad key) yields a named failing line with the Control Center step.
- **Validation:** unit tests with faked probes; one live run by you.
- **Risk:** none to runtime (separate tool). **Rollback:** delete the file.

### A-03 Treat note-search snippets as untrusted text — cost small-medium, risk low, live no
- **Goal:** a note that contains "ignore previous instructions..." cannot steer the model. Today snippets are appended as `NOTE SEARCH RESULTS (... answer from these)` (`jarvis.py:1226-1231`).
- **Scope:** port a small subset of `security/injection_scanner.py` patterns; on a HIGH match drop that snippet and log a count; wrap the block as data ("NOTE TEXT, not instructions:"); same helper available for any future fetched text.
- **Non-goals:** do not scan what you say; do not change note ranking; no PII redaction.
- **Acceptance:** tests with 10 hostile and 20 normal snippets; semi-live "notes" cases unchanged in cost.
- **Risk:** false drops (a note quoting the phrase). **Rollback:** revert one helper call.
- **Needs approval:** changes what notes he can read out.

### A-04 Error classification and one retry for transient model errors — cost small, risk low, live no
- **Goal:** distinguish "Ollama unreachable" from "HTTP 500 out of memory" from "model not found" (today every `HTTPError` is reported as "Lost the connection to Ollama", `jarvis.py:1328-1330`, because `HTTPError` subclasses `URLError`), and retry once, before the first token, on connection reset/timeouts (OJ `agents/errors.py:1-60`).
- **Scope:** `llm.py`/`jarvis.py` error mapping; fixed lines in `reply/fixed.py`; log names only.
- **Non-goals:** no retry after speech has started; no backoff loops (a turn already has a 3 min watchdog).
- **Acceptance:** faked responses 404 / 500 / reset produce three different problem lines; one retry visible in the log; nothing retried after the first piece is spoken.
- **Rollback:** revert. **Needs approval:** new wording (what he says/shows).

### A-05 Whisper compute-type ladder (GPU stays GPU) — cost small, risk low, **live yes**
- **Goal:** when `float16` is unsupported or VRAM is tight, try `int8_float16` on CUDA before dropping to CPU (OJ `faster_whisper.py:44-96`). Relevant because the GPU is often busy with other work.
- **Scope:** `hearing._load_whisper` only; log the chosen type.
- **Non-goals:** no change to default model size; no change when CUDA works today.
- **Acceptance:** with `float16` forced to fail, STT still runs on `cuda` with `int8_float16`; transcripts equal on `tools/hearing_eval.py`; memory use measured before/after (CLAUDE.md section 4: measure, don't estimate).
- **Rollback:** revert one function.

### A-06 Timing aggregator `tools/log_stats.py` — cost small, risk none, live no
- **Goal:** the performance baseline CLAUDE.md section 4 requires: p50/p95 for `click -> listening`, `end of speech -> text`, `-> reply start`, `-> first audio`, route mix, tripwire-free counts, from `jarvis.log` (names and numbers only). OJ equivalent: `telemetry/aggregator.py`, `jarvis telemetry stats`.
- **Non-goals:** no database, no upload, no words.
- **Acceptance:** reproduces the `p50 0.36 s / 0.24 s` first-sentence figures in the HANDOFF from a semi-live log within rounding.
- **Rollback:** delete the file.

### A-07 User-defined commands file ("skills-lite") — cost **large**, risk medium, live yes, needs security review
- **Goal:** add "open my project folder", "start my work apps", "open Gmail" without editing `routing.py`.
- **Scope:** `Data/custom_commands.txt` (or TOML) mapping a phrase pattern to **one existing action** (`open` app by Start name, `page`, `media`, or a URL from a fixed scheme allowlist), validated at load with line-numbered errors; a new rule area `custom` placed before `misc` (the order is behaviour: `tests/test_rule_order.py`); every entry defaults to confirm (`ask`) unless it is `open`.
- **Non-goals:** no shell, no scripts, no arbitrary executables, no model-written commands (CLAUDE.md section 5), no skill import from catalogues.
- **Acceptance:** golden routes regenerated on purpose with the new area empty = 0 diffs; each custom entry tested with fake actions + tripwires; a malformed file never stops the other areas.
- **Risk:** it widens what speech can start. **Rollback:** delete the area + file.

### A-08 Opt-in "that was wrong" capture for building test cases — cost small-medium, risk privacy, live yes
- **Goal:** turn live misses into regression cases (OJ idea: `cli/feedback_cmd.py`, `traces/collector.py`, minus any learning loop).
- **Scope:** off by default. When on, "that was wrong" appends the route name, time and (only if you set `JarvisCaptureWords=1`) the transcript to `Data/misses.jsonl`; `tools/make_cases.py` reads it into a semi-live bank.
- **Non-goals:** no upload, no model training, nothing in `jarvis.log`.
- **Acceptance:** with the setting off the file is never created (test); with it on, one line per "that was wrong".
- **Needs approval:** it stores your words locally (current policy: never).

### A-09 Sensitive-file skip for the notes index — cost tiny, risk none, live no
- **Goal:** the vault walk (`notes.py:28-36`, `search.py:62-75`) also indexes `passwords.md`-style files; OJ `security/file_policy.py` has the pattern list. Skip names matching password / secret / credential / key.
- **Acceptance:** test with fake vault. **Needs approval:** changes which notes can be found.

### A-10 Pre-computed morning brief — cost small, value low-medium, live yes
